# Abastecimento Bridi

Formulário de abastecimento da frota Bridi Madeiras, para uso no celular pelo pessoal do pátio e pelos motoristas.
Para entrar é preciso um código pessoal entregue pelo gestor da frota.

`gestor/` é o painel do gestor da frota (consumo, caminhão-tanque e rotas). Só abre com código de gestor;
a página não guarda dados, tudo vem do banco depois da entrada.
